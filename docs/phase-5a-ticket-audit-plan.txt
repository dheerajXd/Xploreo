1. OBJECTIVE & SCOPE
--------------------------------------------------------------------------------
Phase 5A is an AUDIT-ONLY evaluation of the complete end-to-end support ticket workflow
across all five participating actors:
- Ticket Submitters:
  1. Traveler
  2. Hotel Partner
  3. Guide
  4. Experience Partner
- Ticket Manager / Resolver:
  5. Tech Admin (TA)

The audit determines:
- Which frontend routes, navigation items, and pages exist and whether they are active.
- Whether submitting actors can open ticket forms, create tickets, view their own history,
  and track resolution updates after page refreshes.
- Whether Tech Admin can view all tickets across all submitters, inspect details, and resolve
  tickets with status updates persisting through the backend.
- Whether ticket ownership is derived authoritatively from authenticated session/JWT identity.
- Whether horizontal IDOR and unauthorized resolution vulnerabilities exist.
- The smallest set of changes needed to complete any missing workflow connections.

PROTECTED CONSTRAINTS:
- AUDIT ONLY: Do not modify any application code, configuration, routes, or dependencies.
- Do not launch the website or browser.
- Preserve Phase 4B security fixes and ticket controller/service intact.
